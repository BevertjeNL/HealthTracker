# Algehele audit — 18 november 2026

## Reikwijdte

De repository is nagekeken op toegang tot privégegevens, login en sessies, API-invoer, afhankelijkheden, datastromen, trainingsadvies, foutafhandeling, consistentie, toetsenbordbediening, contrast en responsieve layout. De controle bestond uit codeonderzoek, synthetische regressietests, een schone installatie met `npm ci`, een productiebuild en een lokale browsercontrole van de belangrijkste routes. Dit is geen externe penetratietest of formele WCAG-certificering.

## Bevindingen en aanpassingen

| Ernst | Bevinding | Aanpassing |

| Hoog | Privépagina's vertrouwden voor toegang op de Next.js Proxy, terwijl hun Server Components zelf de database lazen. | Iedere privépagina controleert nu de ondertekende sessie vóór de eerste query. De Proxy blijft een snelle eerste controle. |

| Middel | Niet-vertrouwde metriek-namen konden geërfde objecteigenschappen als ondersteunde Health-metriek laten doorgaan. | Alleen eigen sleutels van de expliciete metriekkaart worden geaccepteerd, met regressietests voor onder meer `__proto__`. |

| Middel | Toekomstgedateerde Health- of Strava-records konden als actuele meting, run of trainingsbelasting meetellen. | Advies, herstel, schema, statistieken en inzichten sluiten zulke records uit, met gerichte tests. |
| Middel | De eerste run zonder historie werd als rust geclassificeerd en acht dagen opgeschoven. | De eerste rustige run is nu voor vandaag beschikbaar. |
| Middel | Ontbrekende HRV-dagen na een zware run telden als traag herstel; dezelfde dag kon als meting vóór de run worden geïnterpreteerd. | Onbekende hersteltijd blijft onbekend; correlaties gebruiken HRV en rusthartslag van de dag vóór de run. Teksten noemen dagwaarden, geen onbewezen ochtendmeting. |
| Laag | De pagina's hadden geen scriptnoncebeleid en sommige privéreacties waren niet expliciet van caching uitgesloten. | Een per verzoek gegenereerde CSP-nonce en `private, no-store` zijn toegevoegd; `X-Powered-By` is uitgezet. |
| Laag | Secundaire tekst, focusringen en grafiekbediening waren op meerdere plaatsen moeilijk leesbaar of alleen met een pointer te gebruiken. | Contrast, zichtbare focus, springlink, toetsenbordbediening van grafieken en schuifhandvatten, paneelfocus, foutmeldingen en tekstgroottes zijn verbeterd. |
| Laag | Onverwachte fouten en ontbrekende pagina's misten een eigen Nederlandse herstelroute. | Er zijn generieke fout- en 404-schermen met een duidelijke terugweg en retry; interne foutdetails worden niet getoond. |
| Laag | De CI gebruikte GitHub Actions die nog op de verwijderde Node 20-runtime waren gebaseerd. | `checkout` en `setup-node` gebruiken de actuele Node 24-releases, vastgepind op hun volledige commit-SHA. |

De belastingverhouding en de correlaties worden nu als beschrijvende signalen gepresenteerd. Ze voorspellen geen blessure of oorzaak. Dat sluit aan bij [methodologische kritiek op acuut/chronische belasting als blessurevoorspeller](https://pubmed.ncbi.nlm.nih.gov/32502973/).

## Gegevens en database

De enige schemawijziging is de nieuwe tabel `login_attempts` met een HMAC van de bron, een teller en het begin van het tijdvenster. Er zijn geen bestaande kolommen hernoemd, verwijderd of omgezet. Bestaande Health- en Strava-waarden zijn niet gemigreerd. De additieve tabel en index zijn via een gecontroleerde `db:push --strict` op de geconfigureerde Neon-verbinding aangemaakt en daarna op bestaan gecontroleerd. Gezondheidswaarden, Strava-tokens, request bodies en wachtwoorden worden niet door de nieuwe code gelogd.

- Een onjuist proefwachtwoord op de productie-login gaf de verwachte generieke foutmelding, geen database- of configuratiefout. Daarmee is de nieuwe inlogtabel ook via de productieapp gecontroleerd.

## Grenzen van deze controle

- `npm audit` op **alle** afhankelijkheden meldt nog 58 waarschuwingen in ontwikkel- en CI-tooling; de directe dev-afhankelijkheden hebben volgens npm momenteel geen automatische fix. Het productiepad meldt nul. Dit verdient opvolging bij nieuwe upstream releases.
- De app gebruikt één wachtwoord zonder tweede factor. De nieuwe limiet is per IP; verspreide pogingen vanaf meerdere IP-adressen blijven een restscenario.
- De CSP staat inline **stijl-attributen** toe voor grafieken. Scripts vereisen wel een verse nonce. Dit is in de lokale browser gecontroleerd.
- Een echte Strava OAuth-herkoppeling, Apple Health-automatisering en een hersteltest van Neon-backups vallen buiten de synthetische tests. Ingelogde productieroutes zijn lokaal met de geconfigureerde database getest; de live login is alleen met een onjuist proefwachtwoord gecontroleerd.
- `vercel inspect` kon zonder Vercel CLI-credentials geen unieke deployment-ID voor beide aliassen tonen. Gelijke build-assets, live headers en de succesvolle Vercel-status van de merge-commit vormen de beschikbare publieke controle.
